====================================================

ТВОЯ ЦЕЛЬ
---------
Собрать рабочий и устойчивый agent.py. Агент должен использовать пилоты,
выбирать прибыльные кампании, соблюдать все лимиты и создавать submission.csv.
Ты один принимаешь финальные технические решения и меняешь agent.py.

РЕКОМЕНДУЕМАЯ МОДЕЛЬ CODEX
--------------------------
Основной выбор: gpt-6-astra, reasoning High.
Используй для архитектуры, реализации agent.py, поиска ошибок и финального ревью.

Если Astra недоступна или нужно экономить лимит:
gpt-6-sol, reasoning High.

Luna для agent.py не используй: задача требует анализа нескольких файлов,
финансовых ограничений и аккуратной интеграции.

Задача: заменить слабый шаблон в agent.py на устойчивого агента, который:
1. Берёт гипотезы из candidate_analysis.md, но не считает historical lift истиной.
2. Проводит разведочные пилоты через env.run_pilot.
3. Учитывает шум пилота PER_CUSTOMER_STD = 0.804 и размер выборки.
4. Повторно проверяет лучшие гипотезы перед масштабированием.

8. Имеет try/except и безопасный fallback при ошибке пилота.
9. Работает детерминированно при фиксированном seed среды.
10. Не использует интернет, runtime-LLM, секреты и обход внутренностей среды.

ПРАКТИЧЕСКАЯ СТРАТЕГИЯ ДЛЯ ПЕРВОЙ ВЕРСИИ
----------------------------------------
Codex должен проверить детали по коду среды, но разумная стартовая схема:

1. Взять 8–12 кандидатов из candidate_analysis.md.
2. Провести первый SMS-пилот примерно по 50–80 клиентов на кандидата.
3. Ранжировать по наблюдаемому lift с поправкой на неопределённость.
4. Провести более крупный повторный пилот для 3–4 лучших кандидатов.
5. Объединить повторные результаты взвешиванием по n_customers.
6. Рассчитать консервативный эффект, а не использовать только среднее.
7. Для каждой исходной ячейки оставить один лучший target_tariff.
8. Выбрать канал по ожидаемому net gain, а не всегда использовать call.

Эта схема не является обязательным хардкодом. Если код среды показывает более
надёжный вариант, Codex должен обосновать и применить его.

КРИТЕРИИ ГОТОВНОСТИ
-------------------
Работа завершена только если:

1. python local_eval.py выполняется без исключений.
2. python local_eval.py --runs 10 завершён.
3. Агент проводит хотя бы один пилот.
4. Нет превышений: 20 пилотов, 15 000 контактов, 100 000 бюджета,
   10 кампаний, 5 000 клиентов на кампанию.
5. Нет отброшенных кампаний из-за неверного тарифа или канала.
6. Код не читает запрещённые внутренности среды.
7. Султанали получил commit SHA и смог независимо повторить тест.

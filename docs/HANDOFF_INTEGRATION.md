`python -m webapp.app` именно Python из .venv-web.

PowerShell до выполнения скрипта: running scripts is disabled.

не менялась. В README и LOCAL_WEB есть ручной путь без ps1.

## Передача команде

После push интегратор передаёт полный SHA, не только имя подвижной ветки.
Участник проверяет git status; при чужих или незнакомых изменениях не
переключает ветку и ничего не удаляет. Для проверки можно создать отдельный
detached worktree от переданного SHA; не использовать git reset --hard.

Асан: запустить реальный сервер, проверить seed 42 через UI, отображение
метрик и фильтров без filter_, ошибки, повторный запуск, desktop/mobile,
локальные ресурсы и отсутствие ошибок консоли. Записать браузер и версию,
точный SHA, команды, фактические результаты и оставшиеся ограничения
в handoff frontend. Исправления — отдельной веткой от общего SHA.

Султанали: в отдельном checkout/worktree проверить первую установку
start_web.ps1 без готовой .venv-web, запуск из другой папки, повторный
запуск, занятой порт, остановку своего сервера; затем pip check, 29 API/service
тестов, local_eval.py и local_eval.py --runs 10. Применить hackathon-eval,
сообщить медиану/min/max/число положительных прогонов и лимиты.
Не менять прибыль или стратегию ради зелёных тестов. Отчёт и исправления —
отдельной QA-веткой от общего SHA.

Оба возвращают проверенный SHA, результат, невыполненные проверки, а при
изменениях — отдельную ветку и полный SHA коммита. Никто не пушит в main
и не регенерирует submission в рамках этой веб-проверки.

# Hackathon Eval

Use this skill only to validate the tariff-campaign agent or prepare its submission. Do not use it for ordinary implementation or data research.

## Before running checks

Read `PROJECT_STATE.md` and `AGENTS.md`. Run commands from the repository root. Do not modify `agent.py` while validating unless the user explicitly asks for a fix.

## Evaluation

Run the check requested by the user:

- One behavior check: `python local_eval.py`
- Stability check: `python local_eval.py --runs 10`
- Submission generation: `python make_submission.py`

For every run, report: exit status, net result, number of pilots, contacts, budget remaining, number of campaigns, and whether any run is negative or changes sign across seeds. Report an exception exactly rather than guessing its cause.

Check the required limits: at most 20 pilots, 15,000 contacts, 100,000 budget, 10 campaigns, and 5,000 customers per campaign.

## Submission

Before reporting a submission as ready, require a successful evaluation and a successfully generated `submission.csv`. State that the file was generated by `make_submission.py`; do not create or edit it manually.

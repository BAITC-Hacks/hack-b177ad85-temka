ГОТОВЫЙ ПРОМПТ ДЛЯ CODEX
-------------------------
Скопируй весь текст ниже в новый чат Codex:

Прочитай полностью AGENTS.md, PROJECT_STATE.md, PARTICIPANT_GUIDE.md,
candidate_analysis.md, data/change_tariff.csv, customer_profile.csv,
data/dict_tariff.csv и tariff_dictionary.csv.

Я Асан, аналитик команды. Основной candidate_analysis.md уже создан.

Задача: провести независимый read-only review candidate_analysis.md и сделать
короткий handoff для Наурызбая. Не переписывай анализ без доказанной ошибки.

Проверь:
1. Соответствуют ли ARPU-сегменты правилам кейса.
2. Нет ли target_tariff, равного current_tariff.
3. Достаточны ли размеры аудитории для пилота.
4. Какие кандидаты имеют n >= 50 и наиболее устойчивую медиану/positive share.
5. Какие кандидаты имеют малую выборку и должны использоваться только как
   второстепенные гипотезы.
6. Какие строки относятся к одной исходной ячейке и конкурируют друг с другом.

Создай или обнови только файл candidate_handoff.txt. В нём должны быть:
- 6–8 приоритетных кандидатов для первого пилота;
- 2–4 запасных кандидата;
- кандидаты с высоким риском из-за малого n;
- точный Python list из tuples
  (current_tariff, arpu_segment, target_tariff), который Наурызбай сможет
  вставить в agent.py;
- краткое объяснение, почему historical lift — только prior.

Не меняй agent.py и код организаторов. Если обнаружишь ошибку в исходном
candidate_analysis.md, сначала опиши её и приведи конкретные строки/расчёты.

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ
-------------------
Файл candidate_handoff.txt должен позволить Наурызбаю за 2 минуты понять:

1. Какие гипотезы пилотировать сначала.
2. Какие target'ы конкурируют за один сегмент.
3. Какие кандидаты нельзя масштабировать без повторного пилота.
4. Какой готовый список вставить в agent.py.
